# Changelog

## [0.1.0] - Unreleased

Initial release of the CodeGraph VS Code extension.

### Added
- Hover provider — shows `📞 N callers · 🧪 M tests cover this · 🕒 last changed X` for any function in 16+ languages.
- Sidebar tree view (CodeGraph activity bar) — expandable callers, tests, last commit, and risk reasons.
- Commands: index current repo, refresh function panel, open settings, copy context pack.
- Settings: REST endpoint, repo name, auto-index on start, hover toggle.
